## Lectures and concepts

- [Java arrays](arrays.md) — one-dimensional, two-dimensional and jagged arrays, exceptions, copies and `java.util.Arrays`.
- [Java strings](strings.md) — concatenation, comparison, common methods, palindromes and formatting.
- [Git basics and SSH keys for GitHub](git-basics.md) — local repository, file states, push to GitHub, SSH keys.
- [Git branches](git-branches.md) — make, move between, rename and delete branches.
- [Git merge conflicts](git-merge-conflicts.md) — merge, the cause of a conflict, conflict markers and resolution.
- [Java standard library](standard-library.md) — libraries, modules, packages, `import`, and source view in the IDE.
- [Java Date and Calendar](date-and-calendar.md) — Unix time, `Date`, `Calendar`, date formats, and `java.time`.
- [Java character streams](character-streams.md) — byte streams and character streams, `Reader` and `Writer`, buffering, charsets, and encoding.
- [Java file streams](file-streams.md) — `FileInputStream` and `FileOutputStream`, character file streams, ZIP archives, `PrintStream` and `PrintWriter`.
- [Java networking](networking.md) — TCP sockets, `Socket` and `ServerSocket`, and the Java 11 `HttpClient`.
- [Java NIO](nio.md) — buffers, channels, selectors, the `java.nio.file` API, and async HTTP.
