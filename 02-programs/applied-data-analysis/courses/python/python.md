## Homework format

The owner supplied two homework notebooks of module 1. The vault does not keep the notebooks or the answers.

| Homework | Supplied | Content | Check |
| --- | --- | --- | --- |
| 1 | By 2026-11-10 | 7 tasks: a dictionary of lists, conditions, a function with a size check, text to a list of words, three classes with inheritance | Autotest cells. Reflection answers in the student's own words |
| 2 | 2026-11-10 | 10 tasks of EDA on a table of students, 30 points | The notebook states that conclusions have the same weight as code |

Rules from the Homework 2 notebook:

- Each task has three solution cells and one conclusion cell. Write the conclusion in your own words.
- The data file must be next to the notebook. In Colab, this is the `/content` folder.
- Before submission, do Restart and run all. All cells must operate and all charts must show.
- Submit the `.ipynb` file or a link on `https://edu.digital.mephi.ru/`.

Deadlines and the grading of Homework 1 are not recorded here. See the [program page](../../applied-data-analysis.md).
